Recettes — acquérir, et faire ressortir

Comment les dépôts se parlent

Quatre dépôts, une base partagée, deux serveurs MCP et un système extérieur qui ne parle à personne. Les échanges ci-dessous sont relevés dans le code, pas supposés.
