## Objective
Déboguer les deux régressions introduites par le routage de tout le HTML fetching via stealth-fetch (session précédente) : Leclerc retournant 0 produits et Auchan retournant des prix `None`.

## Achievements
- **Auchan restauré** : les prix fonctionnent à nouveau (8.45€, 5.52€, 7.62€ vérifiés). `search()` et `scrape_detail()` repassent par le client httpx de session (cookies lark-* liés à l'IP du VPS).
- **Bug camoufox corrigé** : `add_cookies()` Playwright refusait un dict contenant `url` ET `domain` — suppression de `url` (commit `79f02bc` dans stealth-fetch).
- **Leclerc bumped à `max_level=5`** : la cascade essaie désormais les 5 moteurs, mais tous échouent (SSL proxy, DataDome, absence de contexte magasin).
- **Issue stealth-fetch#3 créée** : documente le problème Leclerc (cascade complète en échec, proxy Webshare ~80 % de SSL failures sur Leclerc).

## Decisions
1. **Auchan reste en httpx direct, pas stealth-fetch**
   - **Choix** : reverter `search()` et `scrape_detail()` au client httpx de session
   - **Rationale** : les cookies de session Auchan (lark-*, connect.sid) sont liés à l'IP du VPS. Les router via le proxy résidentiel (IP différente) invalide la session → prix `None`. Auchan n'a pas d'anti-bot, le client direct suffit.
   - **Alternative rejetée** : exporter les cookies vers stealth-fetch — trop fragile (la session est établie par le client httpx, pas par un navigateur)

2. **Leclerc non résolu, tracké comme issue externe**
   - **Choix** : documenter dans stealth-fetch#3 plutôt que contourner
   - **Rationale** : le problème est infrastructurel (proxy résidentiel instable sur Leclerc, DataDome trop sophistiqué pour les moteurs actuels). Le fix viendra du côté stealth-fetch (meilleur proxy ou cookies frais).

## Problems
1. **Auchan prix `None` via stealth-fetch**
   - **Symptôme** : `search_products("beurre")` retournait des résultats sans prix
   - **Cause** : stealth-fetch utilisait le proxy résidentiel → IP différente de celle qui a établi la session Auchan → cookies invalidés → page sans prix
   - **Solution** : reverter au client httpx direct qui partage la session
   - **Prévention** : ne pas router les requêtes Auchan via un proxy — les cookies sont IP-bound

2. **camoufox « Cookie should have either url or domain »**
   - **Symptôme** : erreur Playwright à l'ajout de cookies dans camoufox
   - **Cause** : le dict cookie contenait à la fois `url` et `domain`, Playwright refuse
   - **Solution** : supprimer la clé `url`, garder `domain` + `path`
   - **Prévention** : documenté dans stealth-fetch

3. **Leclerc 0 produits — toute la cascade échoue**
   - **Symptôme** : les 5 moteurs stealth-fetch retournent 0 résultats
   - **Cause** : proxy SSL ~80 % d'échecs sur Leclerc (moteurs 1-3), DataDome bloque les IP datacenter (moteur 4-5), Scrapfly ne transmet pas les cookies (moteur 5)
   - **Solution** : issue stealth-fetch#3 — pas de fix immédiat
   - **Prévention** : nécessite un proxy résidentiel plus fiable ou des cookies navigateur frais
