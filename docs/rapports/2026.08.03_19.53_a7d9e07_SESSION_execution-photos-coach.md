## Objective

Ajouter le suivi de la date d'appréciation (`appreciation_date`) dans les exécutions de recettes, améliorer le scraping de photos (og:image insuffisant à 3/16), et mettre à jour le Cooking Coach `_coach.md` pour documenter tous les nouveaux concepts d'exécution.

## Achievements

- **`appreciation_date` ajouté** : nouvelle colonne dans `recipe_execution`, supportée dans l'API (POST/GET), le formulaire frontend, et l'affichage (quand la date d'appréciation diffère de la date de cuisson)
- **Scraping photo amélioré** : 6 stratégies (og:image, twitter:image, schema.org Recipe JSON-LD, fallback `<img>` large) — filtre des placeholders, User-Agent Mozilla, 5 URLs testées, 200 KB lus
- **4 exécutions historiques seedées** via `POST /api/seed-history` : gratin courge-spaghetti, pancakes banane-avoine, salade lentilles, ninja creami myrtilles
- **Coach `_coach.md` v1.11.0** : documentation de `photo`, `regime_construction`, `lieu_execution` en frontmatter + section historique d'exécution détaillée avec format tableau

## Decisions

1. **Seed historique hardcodé dans l'API plutôt qu'import automatique**
   - **Choix** : route `POST /api/seed-history` avec 4 entrées connues
   - **Rationale** : les données d'exécution ne sont pas dans les conversations IA exportées mais dans le frontmatter vault — un import automatique viendra plus tard
   - **Alternative rejetée** : parser les conversations Claude (vérifié : aucune ne contient de données d'exécution structurées)

2. **6 stratégies de scraping photo en cascade**
   - **Choix** : meta patterns (og:image, twitter:image, JSON-LD Recipe) puis fallback `<img>` large
   - **Rationale** : og:image seul donnait 3/16 — les recettes Creami n'ont pas de source externe
   - **Alternative rejetée** : API externe (complexité, dépendance)

## Problems

1. **Placeholder photo détecté comme vraie image**
   - **Symptome** : `fondant-choco-pois-chiches` récupérait `placeholder.png` de mailofaitmaison.com
   - **Cause** : og:image contenait une URL de placeholder non filtrée
   - **Solution** : ajout de `"placeholder"` dans la liste de filtrage (meta patterns ET `<img>`)
   - **Prevention** : le filtre est maintenant systématique sur toutes les stratégies

2. **Mount VPS en lecture seule pour le coach**
   - **Symptome** : `cat >>` échoue sur `/mnt/dropbox-full/`
   - **Cause** : mount rclone configuré en `ro`
   - **Solution** : téléchargement local, édition, upload via `rclone rcat`
   - **Prevention** : documenté — toute écriture vault depuis le VPS passe par `rclone rcat`
