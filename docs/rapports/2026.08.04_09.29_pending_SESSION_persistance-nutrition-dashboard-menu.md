## Achievements

### Persistance panier + nutrition (issue #14, close)
- Nouvel endpoint `POST /api/shopping/persist-cart` (backend/app.py) : persiste chaque article dans `shopping_product` avec enrichissement live (nutrition, nutriscore, ingrédients, allergènes, caractéristiques, photo, prix/kg) via `backend/auchan.py::find_product_detail()` (recherche catalogue + scrape SSR, pont entre l'UUID interne du panier et l'ID public catalogue)

## Problems
1. **Panier Auchan disparu en cours de nettoyage (fausse alerte)**
   - **Symptôme** : `grocery_get_cart` renvoyait 0 article après une série de suppressions réussies
   - **Cause** : commande passée par Julien entre-temps (pas un bug)
   - **Prévention** : aucune — comportement normal, clarifié par Julien

2. **`ModuleNotFoundError: httpx` après reclonage du VPS**
   - **Symptôme** : 500 sur le nouvel endpoint de persistance juste après le reclonage propre
   - **Cause** : `httpx`/`selectolax` installés à la main dans l'ancien déploiement, jamais déclarés dans `pyproject.toml`
   - **Solution** : ajoutés aux dépendances déclarées
   - **Prévention** : un `pip install .` dans un venv propre est désormais le test de vérité du fichier de dépendances

3. **504 nginx pendant l'enrichissement malgré un traitement serveur réussi**
   - **Symptôme** : le client recevait un 504 mais les 58 lignes s'écrivaient quand même en base
   - **Cause** : `proxy_read_timeout` par défaut (60s) trop court pour 58 enrichissements séquentiels
   - **Solution** : porté à 300s dans `deploy/cooking-manager.nginx.conf`

4. **Menu jamais affiché sur le family dashboard malgré un artefact frais**
   - **Symptôme** : `/api/cuisine` renvoyait le bon menu, mais l'écran affichait toujours juillet
   - **Cause** : le front n'appelle jamais `/api/cuisine` — il appelle `/api/data`, qui privilégiait un export Windows figé depuis le 11 juillet dès qu'il existait
   - **Solution** : suppression du chemin bridge, lecture live systématique
   - **Prévention** : `family-manager#41` documente le mécanisme pour éviter la régression
