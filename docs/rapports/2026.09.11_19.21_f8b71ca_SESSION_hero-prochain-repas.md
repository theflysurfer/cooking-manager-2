## Objective
Afficher le prochain repas à préparer en tête de la page Semaine — réponse
immédiate à « c'est quoi ce soir ? » sans scroller.

## Achievements
- `findNextMeal(meals, nowOverride)` : logique pure, slot par heure (<10h breakfast,
  <14h lunch, <17h snack, ≥17h dinner), ignore jours passés et repas servis/skipés
- `renderNextMeal` : hero card avec photo+overlay ou fallback initiale, aria-label,
  tag restes, flèche lien recette
- CSS responsive 88→128px, `-webkit-` prefixes, iOS 12 safe (gate 100/100)
- 22 tests JS dans `web/test_next_meal.html` couvrant 9 acceptance criteria
- Workflow suivi : spec (AC1-AC9) → TDD (tests RED→GREEN) → build → deploy → vérification Chrome Relay
- Déployé sur VPS, vérifié visuellement via Chrome Relay (screenshot du hero)

## Decisions
1. **Test JS en fichier HTML auto-exécutable** — **Choix** : `web/test_next_meal.html`
   avec harness assert minimal, exécutable via Node ou navigateur — **Rationale** :
   pas de framework JS dans le projet (zéro build), c'est le plus léger qui couvre
   la logique — **Alternative rejetée** : dupliquer la logique en Python pour pytest

2. **`nowOverride` paramètre de test** — **Choix** : `findNextMeal(meals, nowOverride)`
   accepte une date injectable — **Rationale** : rend la fonction testable sans
   monkey-patch de `Date`, et le paramètre est ignoré en prod (appelé sans)
