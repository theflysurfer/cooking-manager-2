## Decisions

1. **La recherche n'a pas besoin d'authentification — seulement d'un contexte magasin**
   - **Choix** : self-heal par `journey/update` plutôt que d'exiger une session vivante
   - **Rationale** : mesuré en session anonyme (22 offer_id) ; le panier seul exige `connect.sid`
2. **CHV headful sous xvfb** (au lieu de headless-shell)
   - **Rationale** : Google rejette le headless-shell avant même l'account chooser ; mesuré les deux modes
   - **Coût accepté** : un peu plus de RAM par run (~25 s CPU)
3. **Le sort du « repo auchan api » (question Julien mid-session)** : il n'existe
   AUCUN repo auchan-api (ni local, ni GitHub, ni registry). Le client vit dans
   le monorepo MCP VPS — la consolidation de code était déjà faite depuis le
   9/08. Rien à intégrer. Seul leclerc-drive-api existe comme repo d'enseigne,
   et c'est un autre modèle (package importé par CM2) — pour Auchan, la
   décision « MCP VPS voie unique » exclut ce modèle

## Problems

1. **Google rejette le sign-in headless** — `v3/signin/rejected` en
   headless-shell ; en headful/xvfb le chooser passe mais le **mur passkey**
   (`signin/challenge/pk`) reste infranchissable sans passkey sur la machine.
   Prevention : options documentées dans #1 (passkey virtuelle CDP vs statu quo)
2. **claude.ai mort sur le VPS** — depuis le passage headful, warm →
   `login?from=logout` ; la transplantation des cookies PC est refusée
   (session liée au device ?). Issue **cookie-health-vps#2** créée —
   l'export ai-chat consommera un blob mort
3. **`remove_from_cart` 500 sur certains articles** (bug Auchan connu du
   9/08) — le « Double concentré boîte » a fini par partir (le 500 suivait un
   retrait déjà effectué) ; aucun article n'a résisté au final
4. **Déploiements tronqués par le harnais** (bug Git Bash documenté) — le
   `finish_deploy` du sync-code.sh n'a pas redémarré le service (code sur
   disque, ancien code en mémoire, détecté par `ExecMainStartTimestamp`) ;
   pareil pour le tar CHV. Parade appliquée : restart explicite + vérification
   marqueur + grep de symbole, à chaque fois
