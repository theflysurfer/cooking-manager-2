## Decisions

1. **Courses = repas restants, jamais la shopping-list brute** — **Choix** : SQL
   `mm.day >= aujourd'hui` × stock. **Rationale** : la liste additionne les repas déjà
   mangés (#94), rien ne décrémente le stock. **Alternative rejetée** : lire les
   `absent`/`insuffisant` de `/shopping-list` (double le passé).
2. **Validation stock par blocs de ~4** — **Choix** : découper par rayon, une question
   par bloc, PATCH immédiat. **Rationale** : un mur de 14 lignes est illisible pour Julien.
   Encodé dans weekly-prep 3.1bis.
3. **Fix du MCP à la source, pas contournement** — **Choix** : `name = name or tool` dans
   `mcp_compact.py`. **Rationale** : « dès que tu vois une erreur, corrige le mcp » (Julien).
4. **Reseed Auchan = mint local de connect.sid** — **Choix** : rejouer les cookies Keycloak
   en curl_cffi `allow_redirects=True` pour que le serveur pose `connect.sid`, puis reseed
   du jar complet. **Rationale** : l'extraction post-login ne porte pas `connect.sid`
   (httpOnly, minté au callback) → écrire les seuls Keycloak = client ANONYME.

## Problems

1. **Restart du MCP a tué la session Auchan** — **Symptôme** : après restart (nécessaire
   pour charger le fix), `authenticated:false`. **Cause** : la seule copie vivante du
   `connect.sid` était en mémoire du process (roulé ~2,9 j) ; VPS disk + profil local
   déjà morts (cookie-health `DEAD: auchan.fr`). **Solution** : reseed HydraSpecter + mint.
   **Prévention** : documenté dans la drive skill (procédure vérifiée) + ref-web-session-auth.
2. **Chrome Relay ne peut pas exporter les cookies** — **Symptôme** : login réussi dans le
   vrai Chrome inexploitable pour le reseed. **Cause** : aucun tool cookies, `js` ne lit pas
   le httpOnly. **Solution** : HydraSpecter (`POST /create` → `/navigate` → clic Google via
   `/evaluate` clé `expression` → `GET /cookies`). **Prévention** : corrigé dans les 2 skills.
3. **cookie-health warm marque auchan DEAD malgré cookies valides** — **Cause** :
   `KC_AUTH_SESSION_HASH` expire en minutes ; le warm ne propage donc pas au SecretStore.
   **Solution** : écrire `COOKIES_AUCHAN_FR` en direct via `reseed_vps.py` sous
   `systemd-run` (`mcp-key-auchan` / `User=mcp-run`).
