## Objective
Resoudre trois issues : #15 (nutriscore/allergenes vides a l'enrichissement), #28 (filtrer la liste de courses par date) et #29 (couverts ajustables par repas).

## Achievements
- **#15 — Enrichissement Open Food Facts** : extraction EAN depuis la fiche produit Auchan (groupe "Ref / EAN"), extraction des allergenes en MAJUSCULES dans le texte d'ingredients (reglementation UE), puis appel OFF (`/api/v2/product/{ean}`) pour nutriscore, allergenes structures et ingredients manquants. Dictionnaire de traduction des 14 allergenes reglementes EN→FR. Issue fermee.
- **#28 — Filtre `from_date` sur la liste de courses** : parametre `from_date` sur `GET /api/menus/{slug}/shopping-list` filtre les repas dont le jour est passe. Toggle front "Semaine / Restant" dans la vue courses.
- **#29 — Couverts par repas** : colonne `menu_meal.covers` (nullable, fallback au defaut global). Bouton "Couverts" sur chaque repas dans la vue menu. La liste de courses utilise le nombre de couverts specifique au repas pour le calcul des quantites.
- **Migrations manquantes detectees au ship** : `ALTER TABLE shopping_product ADD COLUMN IF NOT EXISTS ean TEXT` et `ALTER TABLE menu_meal ADD COLUMN IF NOT EXISTS covers INTEGER` ajoutees dans `MIGRATIONS_SQL` — les CREATE TABLE portaient les colonnes mais le VPS a deja les tables existantes.
- **Ruff B904 preexistant** : deux `raise HTTPException(503)` sans `from None` dans les endpoints vocaux, corriges.

## Decisions
1. **Open Food Facts plutot que scraping Auchan pour le nutriscore**
   - **Choix** : appel API OFF via EAN barcode extrait de la fiche Auchan.
   - **Rationale** : Auchan n'affiche plus le nutriscore en image sur les fiches produit (verifie via HydraSpecter). OFF est gratuit, fiable et structure (nutriscore_grade, allergens_tags).
   - **Alternative rejetee** : scraping d'image nutriscore Auchan — le selecteur ne matche plus rien.

2. **Double extraction des allergenes (regex EU + OFF)**
   - **Choix** : regex MAJUSCULES dans le texte d'ingredients (norme UE) en premier, OFF en fallback.
   - **Rationale** : la plupart des produits Auchan affichent les allergenes en majuscules dans le texte (pas dans un champ separe). OFF complete quand le texte est absent ou non structure.

## Problems
1. **Colonnes absentes en production (detecte au ship, corrige)**
   - **Symptome** : `ean` et `covers` dans les CREATE TABLE mais pas dans MIGRATIONS_SQL.
   - **Cause** : `CREATE TABLE IF NOT EXISTS` ne rajoute pas de colonnes a une table existante.
   - **Solution** : deux `ALTER TABLE ADD COLUMN IF NOT EXISTS` dans MIGRATIONS_SQL.
   - **Prevention** : toute nouvelle colonne = un ALTER dans MIGRATIONS_SQL, toujours.

2. **Flex `gap` ecrit puis immediatement corrige**
   - **Symptome** : `.slot__actions { gap: 6px }` ecrit par reflexe.
   - **Cause** : `gap` en flex necessite Safari 14.5, la cible est Safari 12.
   - **Solution** : remplace par `> * + * { margin-left: 6px }`.
