brouillon de commande chez Auchan** sur un panier vide — `orderId

que `create_order` n'est **pas** appelé (`client.calls == 0`).

**avant** toute commande. Les deux garde-fous sont indépendants.

### mcp-vps#188 — les 26 échecs venaient des fixtures (tâche 4)

`_token_is_live` exige un `exp` lisible dans le JWT. Les tests posaient `"tok"` et
`"abc.def.ghi"` : sans `exp`, le jeton était déclaré mort, et le client partait
**re-frapper un jeton sur le réseau** sous les mocks. Le code de production est
juste — c'est le bon sens de la règle : un jeton dont on ne sait pas lire
l'expiration ne se croit pas sur parole.

Les tests posent maintenant un JWT dont l'`exp` est réel (`live_token()`), et le
test de non-régression « pas de fallback silencieux » simule un SSO muet au lieu de
laisser partir l'appel. **32 passés, zéro échec.**
