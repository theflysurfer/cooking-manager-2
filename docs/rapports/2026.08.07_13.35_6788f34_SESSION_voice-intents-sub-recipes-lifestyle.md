## Decisions
1. **`currentRecipeSlug()` pour les intents contextuels**
   - **Choix** : extraire le slug depuis `location.hash` (`#/recette/<slug>`) plutôt que modifier le pipeline audio
   - **Rationale** : les intents `recipe_note` et `recipe_edit_step` ont besoin du slug de la recette affichée ; le hash est la source de vérité côté front

2. **Marmiton comme lane IDENTITY**
   - **Choix** : scrape structuré sous Hydra rendant titre, note, temps, difficulté — classé IDENTITY (nomme des recettes)
   - **Rationale** : suit le même contrat que `alternativeto`/`producthunt` — des faits durs extraits du DOM, pas des titres de pages web

## Problems
1. **Mount VPS en lecture seule**
   - **Symptôme** : écriture de houmous-maison.md impossible sur `/mnt/dropbox-full/`
   - **Cause** : le mount rclone est en lecture seule par conception
   - **Solution** : écrire localement puis `rclone copy` vers Dropbox cloud

2. **Mauvais import `normalize_name`**
   - **Symptôme** : `ImportError` sur `from cooking_manager.normalizer import normalize_name`
   - **Cause** : la fonction vit dans `cooking_manager.ingredients`, pas `normalizer`
   - **Solution** : corriger l'import

3. **`showMicPanel` appelé avec 4 arguments**
   - **Symptôme** : erreur JS — la fonction n'accepte que 3 paramètres
   - **Solution** : utiliser le paramètre `transcript` pour les messages de confirmation, `null` pour intent en cas d'erreur
