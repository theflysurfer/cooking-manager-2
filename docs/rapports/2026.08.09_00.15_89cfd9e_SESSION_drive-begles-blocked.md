## Problème central — mauvais MCP utilisé

Le connecteur **claude.ai** `Auchan Drive` (`mcp__claude_ai_Auchan_Drive__tools`) a été utilisé par erreur. Son `grocery_search` ne résout **pas** les `offer_id` (retourne `""`) — ce qui bloque `grocery_add_to_cart` (erreur 500).

Le **MCP local** `backend/auchan_mcp.py` est le bon outil. Il a été construit le 2026-08-03, fait 22 ajouts au panier ce jour-là, et expose 7 tools complets : `search`, `detail`, `cart get/add/remove/update`, `set_token`. **C'est lui qui remplace le connecteur claude.ai** (diary `auchan-api-shopping` du 2026-08-03).

### Pourquoi le MCP local n'était pas branché
Il fonctionne en **stdio** (`python -m backend.auchan_mcp`) — il faut le lancer dans la session ou le connecter via l'orchestrateur MCP (port 8750). Il n'était pas déclaré dans les MCP de la session.

### Ce qu'il faut pour la prochaine session
1. **Lancer le MCP local** : `python -m backend.auchan_mcp` (stdio) ou le brancher via l'orchestrateur
2. **Récupérer un token Bearer frais** : soit depuis les cookies HydraSpecter (session Bègles sauvegardée), soit via `set_token` après extraction réseau
3. **Remplir le panier** avec la liste ci-dessous
