- **Skill pipeline mise à jour** : Step 9 enrichi avec deux gotchas (recherche en français simple, params snake_case)

## Decisions
1. **Injection SVG plutôt que post-traitement d'image**
   - **Choix** : annoter directement dans le DOM via `browser_evaluate` avant le screenshot
   - **Rationale** : pixel-perfect, pas besoin de bibliothèque image (PIL/Canvas), annotations collées aux éléments réels
   - **Alternative rejetée** : post-traitement sur image statique (coordonnées à recalculer, moins fiable)

2. **Ne pas installer de skills tierces**
   - **Choix** : auditer les repos et prendre les bonnes idées, sans installer
   - **Rationale** : déjà beaucoup d'outils (HydraSpecter fait le gros du travail), les skills tierces ajoutent des dépendances pour peu de valeur incrémentale

## Problems
1. **Citrons verts introuvables sur Auchan**
   - **Symptôme** : recherche retournait uniquement des sodas
   - **Cause** : recherche « citron vert lime » — le mot « lime » en anglais biaisait vers les boissons
   - **Solution** : rechercher « citron vert » seul
   - **Prévention** : documenté dans la skill pipeline Step 9

2. **Repo `design-extract` inexistant**
   - **Symptôme** : 404 sur GitHub
   - **Cause** : hallucination de l'agent de recherche (Haiku)
   - **Solution** : ignoré, le vrai candidat serait `arvindrk/extract-design-system` mais non prioritaire
