## Decisions
1. **Bascule macros sur DB** — **Choix** : `_load_food_base_from_db()` remplace `load_food_base_cached()` — **Rationale** : le vault .md est fragile (rclone mount, null-string #85), la DB a déjà les 166 entrées importées — **Alternative rejetée** : garder le vault avec le fix #85 seul
2. **NON_PURCHASE en frozenset** — **Choix** : liste fermée (eau, sel, poivre, glaçon) — **Rationale** : les faux positifs sont un ensemble fini et stable — **Alternative rejetée** : heuristique par catégorie d'ingrédient

## Problems
1. **Test assertion trop fragile** — **Symptôme** : `assert "inventaire" in v.reason` cassé après #84 — **Cause** : le message change car le check per-item fire avant le check global — **Solution** : asserter `v.assumed_empty` au lieu de la prose — **Prévention** : tester le comportement, pas le message
