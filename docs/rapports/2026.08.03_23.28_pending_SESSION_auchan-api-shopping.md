## Objective
Construire l'API Auchan Drive (reverse-engineering), créer un MCP local pour piloter le panier, remplir le panier de courses pour la semaine, et créer la skill pipeline hebdomadaire (vault → courses → macros).

- **API Auchan Drive reverse-engineered** (`backend/auchan.py`) : client complet avec auth Keycloak, cart CRUD (add/remove/update), recherche produits SSR, scraping détail produit (nutrition, ingrédients, allergènes, nutriscore, photos)

- **Issues closes** : #8 (skill pipeline), #9 (remove cart), #10 (API client), #11 (MCP server), #12 (chore close)

## Decisions
1. **Scraping SSR plutôt qu'API pour les produits**
   - **Choix** : selectolax sur le HTML rendu
   - **Rationale** : les pages produit et la recherche sont entièrement SSR, aucun endpoint API découvert pour nutrition/ingrédients
   - **Alternative rejetée** : API interne Gravitee — ne couvre que le panier, pas le catalogue

2. **JSON temporaire avant PostgreSQL pour les choix de courses**
   - **Choix** : `data/shopping_choices_*.json` → import en DB au ship
   - **Rationale** : itérer rapidement sur les critères de sélection (local, sans scandale, prix/kg) avant de figer le schéma

3. **Garde-manger dans le vault Obsidian**
   - **Choix** : `Noyau/Cuisine/Garde-manger.md` avec checklist `[x]`/`[ ]`
   - **Rationale** : accessible depuis Obsidian mobile, format naturel pour mise à jour manuelle

## Problems
1. **Suppression du panier impossible via MCP claude.ai**
   - **Symptôme** : `grocery_add_to_cart` avec quantity=0 retourne 500
   - **Cause** : l'API utilise un `id` interne (UUID) distinct du `productId` — il faut GET le panier d'abord
   - **Solution** : reverse-engineering via HydraSpecter (clic « Supprimer », capture réseau) → `desiredQuantity: 0` avec l'`id` interne
   - **Prévention** : méthode `remove_from_cart` dans le client qui fait le GET+POST automatiquement

2. **Produits manquants dans le panier**
   - **Symptôme** : œufs, pâtes/riz, oignons/ail absents
   - **Cause** : courses faites sans croiser les recettes du menu — liste construite « de mémoire »
   - **Solution** : identifié, reste à implémenter le calcul différentiel (skill step 5→8)
   - **Prévention** : la skill pipeline impose le croisement menu × ingrédients avant les courses
