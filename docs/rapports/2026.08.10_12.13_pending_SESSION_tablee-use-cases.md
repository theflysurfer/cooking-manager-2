## Objective

Corriger le bug « Hors foyer — pas de repas à préparer » affiché pour le menu
vacances Bègles malgré des repas planifiés, puis définir le vocabulaire et les
cas d'usage de la composition de table.

## Achievements

- **Fix bug Bègles** (5c0085b) — `web/app.js` : le `return` dans `if (!atHome)`
  empêchait le rendu des repas. Retiré → les repas s'affichent quel que soit le
  statut de présence. Déployé et vérifié sur le VPS.
- **Vocabulaire « tablée »** — remplace « présence » qui confondait trois
  dimensions : Tablée (T = qui mange), Cuisine (C = qui prépare), Lieu (L = où).
  Le modèle actuel `at_home: true/false` mélange les trois.
- **Rôle R8 « Le régisseur »** — gère qui est à table, avec job story.
- **40 cas d'usage documentés** (`docs/conception/USE_CASES_TABLEE.md`) — 7
  catégories (A à G), familles SC-25 à SC-32 rattachées à MOMENTS.md.
  Couverture mesurée : 4 modélisé (10 %), 5 partiel (12,5 %), 31 absent (77,5 %).
- **Artefact HTML** — tableau de bord visuel des cas d'usage au format Qustodio
  (catégories, tags de couverture, badges dimensions, statistiques).
- **Nettoyage Auchan** — README.md purgé des références Auchan (22 suppressions).
  CLAUDE.md purgé : section « Auchan Drive API », « Persistance + enrichissement
  nutritionnel », lignes architecture, 5 gotchas Auchan. Orphelin
  `tests/test_auchan_parser.py` supprimé.

## Decisions

1. **Tablée plutôt que présence**
   - **Choix** : trois dimensions indépendantes (T/C/L) au lieu du booléen `at_home`
   - **Rationale** : un séjour avec cuisine (Bègles) est T=famille+invités,
     C=on cuisine, L=ailleurs — `at_home=false` casse tout
   - **Alternative rejetée** : enrichir `at_home` avec des flags → ne résout pas
     les invités ni la cuisine pour ailleurs

2. **Documenter avant d'implémenter**
   - **Choix** : 40 cas d'usage cartographiés, aucun code de modélisation
   - **Rationale** : le bug Bègles est corrigé côté front (workaround) ; la
     modélisation T/C/L est un chantier de fond qui mérite un design complet

## Problems

1. **Bug « Hors foyer »**
   - **Symptôme** : menu Bègles affiche « pas de repas à préparer » pour 4 jours
   - **Cause** : `web/app.js` ligne 98 — `return` dans le bloc `if (!atHome)`
     court-circuitait le rendu des repas
   - **Solution** : retirer le `return`, garder `away = true` pour l'affichage
     informatif
   - **Prévention** : la modélisation T/C/L éliminera le booléen `at_home`
