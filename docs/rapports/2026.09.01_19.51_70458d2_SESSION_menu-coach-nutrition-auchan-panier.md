## Decisions
1. **Pas de reverse-engineering à l'aveugle du paiement Auchan** — **Choix**: ouvrir une issue documentant le besoin d'une capture réseau réelle avant d'écrire du code de checkout — **Rationale**: un paiement carte passe presque toujours par 3D Secure (humain requis), et deviner des payloads sur un flux financier risque un double débit ou une commande cassée — **Alternative rejetée**: implémenter directement depuis la lecture de `client.py` existant
2. **Ne pas croire un compte-rendu « fait » sans le vérifier dans le code** — **Choix**: vérifier via 3 sources indépendantes (recherche de code, git log, liste d'outils MCP en direct) avant d'agir sur l'affirmation du commentaire issue #174 — **Rationale**: les trois sources concordaient sur « rien n'existe », contredisant le commentaire — **Alternative rejetée**: faire confiance au commentaire et tenter d'appeler des outils MCP inexistants

## Problems
1. **Panier Auchan invisible côté navigateur** — **Symptôme**: 0,00 € affiché sur auchan.fr alors que le Coach Nutrition annonçait un panier rempli — **Cause**: session MCP VPS et session navigateur personnel sont deux paniers serveur distincts sur le même compte — **Solution**: expliqué à Julien, panier réel confirmé via l'outil — **Prévention**: aucune automatisée ; le gap de checkout (issue #174) fermerait ce trou de confusion pour de bon
2. **GITHUB_TOKEN invalide (local + wrapper VPS)** — **Symptôme**: `401 Bad credentials` sur `gh` CLI et sur le connecteur GitHub MCP claude.ai — **Cause**: PAT expiré/révoqué des deux côtés — **Solution**: Julien a stocké un nouveau PAT en variable utilisateur Windows ; lu à chaud via `[Environment]::GetEnvironmentVariable("GITHUB_TOKEN","User")` en PowerShell pour contourner l'env du shell déjà démarré — **Prévention**: pas de rotation automatique en place, à surveiller
3. **6 articles du garde-manger vault listés « ok » mais absents réellement** — **Symptôme**: menu construit autour d'ingrédients qui n'existent pas — **Cause**: inventaire manuel non mis à jour après consommation réelle — **Solution**: corrigé fichier par fichier avec la date et la source (Julien, constaté 2026-09-01) — **Prévention**: aucune structurelle ; le garde-manger vault et la DB de l'app CM2 restent deux systèmes non synchronisés (ajouté en Gotcha CLAUDE.md)
4. **Kcal des soupes Danival mal interprété** — **Symptôme**: sous-estimation ×5 de la contribution calorique d'un repas — **Cause**: la fiche vault donnait un chiffre "74 kcal" sans préciser l'unité (100 ml vs sachet) — **Solution**: vérifié en ligne (OpenFoodFacts + Fatsecret), fiche corrigée avec unité + source — **Prévention**: aucune fiche vault sans unité explicite ne devrait plus être prise au chiffre nu
